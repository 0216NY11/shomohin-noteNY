# 消耗品ノート（iPhone用Webアプリ）

## 機能
- 品名、購入価格、購入日、カテゴリ、店名、メモを記録
- 品目ごとの最新価格と前回比を表示
- 品名・店名検索、カテゴリ絞り込み
- 品目別／全体の購入履歴、編集、削除、再購入記録
- JSONバックアップの書き出しと復元
- HTTPSで公開した場合のホーム画面アプリ表示・簡易オフライン対応

## 重要：データ保存
購入記録はブラウザの localStorage に保存されます。Safariのサイトデータ消去やブラウザ環境の変更で失われる可能性があるため、定期的に「バックアップ」を押し、JSONファイルを「ファイル」アプリのiCloud Driveなどに保存してください。機種変更後は新しいiPhoneでアプリを開き、バックアップJSONを選んで復元します。

## iPhoneに追加する方法
1. このフォルダ一式をHTTPS対応の静的ホスティングにアップロードします（例：GitHub Pagesなど）。index.html単体の「ファイル」アプリからの表示では、PWAとしてのインストールやオフライン機能が完全には動きません。
2. iPhoneのSafariで公開URLを開きます。
3. 共有ボタン →「ホーム画面に追加」→「追加」。
4. アプリを起動して「バックアップ」を試し、JSONファイルが保存できることを確認します。

## ファイル
- index.html: アプリ本体
- manifest.json: ホーム画面アプリ設定
- sw.js: キャッシュによる簡易オフライン対応
